# 提问库（部署 ASK）

> EN: Which deployment questions must be asked, which may default, and what each answer changes.

**用途**：部署模式的唯一问题清单。`BOOTSTRAP.md` §4 指向本文件；`PROTOCOL.md` §3.3 规定问法，§4 规定硬停点。两份冲突时按更严格的那份执行。
**范围**：只覆盖“把规则书装进用户 harness”的部署；不覆盖改规则、开发、迁移。
**闸门**：任何必问项没有答案，不许往用户 home 写文件。用户说“不知道”按没答处理；只有可默认项才可按默认执行，并记 `delegated`。
**档位**：**必问** = 不答不动手，默认值只是建议；**可默认** = 不答或说“随便/你定” → 用默认值，`answers[]` 记 `source: delegated`，报告单列；**自动探测** = 先跑命令，有值不问，`unknown` 或与口述冲突才升级为必问。
**问法**：一次最多 4 条；按“必问 → 条件必问 → 可默认”排序；每条带编号、默认值、猜错后果；磁盘能查的不问；同一 STOP 多文件合成一条；必问项不可代答（STOP-14）；两轮不答 → `NEEDS-INPUT.md` + `plan.md`（标 `NOT APPLIED`）→ `BLOCKED`。

## 12 问

| ID | 档 | 问什么 | 为什么必须问 | 选项 | 默认值 | 判据（何时问 / 何时默认） | 不问会怎样 |
|---|---|---|---|---|---|---|---|
| E1 | 自动探测 | 哪个 OS / shell / 架构：Windows PowerShell 5.1+、PowerShell 7+、macOS、Linux、WSL？ | 决定跑 `install.ps1` 还是 `install.sh`，以及路径、编码、CRLF；选错会装到一半失败。 | PowerShell 5.1+ / PowerShell 7+ / macOS / Linux / WSL / 其他 | 探测值；探测不到无默认 | `uname -srm` 或 `$PSVersionTable.PSVersion` 有值 → 不问；`unknown`、WSL、远程 → 必问（STOP-13）。 | 用错脚本方言；装进 WSL 的 home，Windows harness 读不到。 |
| E2 | 自动探测 | 装给哪个 harness：omp、Codex、Claude Code、全部？ | 三套入口、目录、生效方式不同；一次改三套，一套错全烂（STOP-02）。 | omp / codex / claude / all | 只装探测到的那套；0 或 ≥2 套无默认 | 恰好 1 套且配置非空 → 可默认；0 或 ≥2 套 → 必问；说“都用” → all，逐套串行。 | 白装；或用户看不到规则；三套同时改，回滚互相污染。 |
| E3 | 必问 | 装到用户级还是项目级？ | 用户级对所有项目生效；项目级只对当前仓库生效，installer 不保证 harness 会读（STOP-06）。 | 用户级（`$HOME`，installer 支持）/ 项目级（手工，未验证）/ 只出计划不装 | 用户级 | 说“只这个项目/别污染全局” → 必问并说明项目级未验证；说“全局/所有项目” → 用户级；含糊 → 必问。 | 装到项目里不生效，用户以为装好；或全局污染别的项目。 |
| E4 | 必问 | 入口文件已有非空规则（`AGENTS.md` / `CLAUDE.md` / `RULES.md` / `config.toml` / `settings.json`），选哪种处理方式（既有键默认不改，要改逐项点名）？ | 覆盖会毁掉用户攒的规则；改 model/provider/permissions 可能让 harness 起不来（STOP-01/04）。 | 追加 managed block（`agentrule:entry v1`，需 `--force`）/ 单独文件 + 指针（手工）/ 跳过（手工：不调用脚本，只写报告）/ 替换或并存（手工）；既有键默认不改，要改逐项点名 | 追加块、不改既有键、不覆盖原文 | 文件非空 → 必问；要改既有键 → 逐键给旧值→新值（STOP-04）；文件空/不存在 → 不问。 | 覆盖用户两年的规则；或改坏 model/provider，harness 起不来。 |
| P1 | 必问 | 要装门（hooks）吗？ | 本仓不带门；`../protocol/03-gates.md` 只有最小伪码。装门要用户自己实现或提供代码，门会拦命令。 | 不装，只有约定（默认）/ 装（用户提供代码路径，逐条 review）/ 先看门清单再定 | 不装；报告写明“本机没有机器门” | 所有部署都问；codex/claude 说明无门可装；说“只要规则” → 记录后跳过。 | 用户以为有 7 条自动门，实际只有文字；或装了门挡住自己的命令。 |
| P2 | 必问 | 门拦了以后，允许临时放行吗？ | 放行方式决定门是不是真的门；默认不放行，防止 agent 自己绕过（STOP-03）。 | 不放行（改代码/换路径/问用户）/ 单次放行并写日志 / 全局临时关（不推荐，需书面同意） | 不放行 | P1=装门 → 必问；P1=不装 → 仍问一次，确认“没有门可放行”；说“别拦我” → 解释后仍默认不放行。 | 用户被门挡住无法干活；或 agent 私自 `--no-verify`、关 hook。 |
| P3 | 必问 | 规则书要自动更新吗？ | 自动更新会改掉已验收的规则；不更新会留旧版。installer 没有更新逻辑，只有 `--verify`。 | 不自动（手动 `git pull` + 重跑 `--verify`）/ 启动时提示有新版本 / 自动更新（需外部定时器，本仓不提供） | 不自动 | 所有部署都问；仓库没有 VERSION 时只支持手动。 | 自动改掉已验收的规则；或用户以为会自动更新，实际一直是旧版。 |
| P4 | 必问 | 允许执行仓库里的安装脚本吗（`install.ps1` 或 `install.sh`）？ | 脚本会写 home 下的配置；陌生脚本拿到 shell 权限（STOP-08）。 | 允许执行（先看 `--dry-run` 输出）/ 只允许 `--dry-run` / 不执行，按 `plan.md` 手工写 | 只允许 `--dry-run`；确认计划后才 APPLY | 流程要用脚本写盘 → 必问；用户已明确“跑安装器” → 记录授权后执行；只读演示 → 不问。 | 用户以为只看计划，脚本却写了盘；或不敢跑，部署停在 PLAN。 |
| B1 | 必问 | 除了 harness 配置目录和状态目录，还允许写哪些目录？ | 写错目录会污染项目或越权；协议只授权 harness 目录 + 状态目录。 | 只写 harness 目录 + `~/.agentrule-deploy/`（默认）/ 加当前项目目录（只读展示，不写）/ 自定义白名单（逐条列出） | 只写 harness 目录 + 状态目录 | 要求项目级或写项目 → 必问；纯用户级 → 可默认；说“随便写” → 仍按默认，不扩大。 | agent 写进项目、桌面、其他 harness；用户不知道哪些文件被改。 |
| B2 | 可默认 | 覆盖前备份放到哪（选“不备份”则只允许新建、不覆盖）？ | 没备份的覆盖不可回滚；默认路径不可写时写盘会中途失败（STOP-11）。 | 每次覆盖前备份到 `<target>/.backup-<timestamp>/`（默认）/ 用户指定目录 / 不备份（则只允许新建，不覆盖） | 每次覆盖前备份到 `<target>/.backup-<timestamp>/` | 有覆盖 → 默认备份；默认路径不可写、空间不足、用户指定 → 必问；无覆盖 → 不问。 | 覆盖后无法还原；或备份写不进去，APPLY 中断。 |
| B3 | 必问 | 卸载时删什么？ | 删错会丢用户配置；协议要求 manifest 驱动，用户改过的文件先给 diff。 | 只删 manifest 记录的文件 + managed block（默认）/ 只删标记块，保留文件 / 整目录删除（拒绝）/ 逐项确认 | manifest 驱动（`<target>/.agentrule-deploy/<run-id>/manifest.json`）；改过的文件先 diff | 用户执行卸载 → 必问；安装阶段只把默认写进 `report.md`；当前 hash ≠ `after_sha256` → 必问。 | 误删用户配置或整个 harness 目录；改过的文件被静默还原。 |
| B4 | 必问 | 目标有凭据文件（`.env` / `auth.json` / `*.pem` / `*token*`），或计划要删/移用户文件，怎么处理？ | 读或复制会泄露密钥；删/移不可逆（STOP-12；硬地板要求删源前记录副本 + sha256）。 | 凭据不读不复制、删/移不删不移（默认）/ 凭据只记录路径和 hash，不读内容 / 删/移先移到备份目录（保留原文件）/ 逐项确认后删除 | 凭据不读不复制；删/移不删不移 | 探测到凭据文件，或 `plan.md` 含 delete/move → 必问；没有 → 不问；工具意外读到内容 → 停，报告不写值。 | 密钥进日志/报告/commit；或误删用户文件、移动后原路径失效。 |

## 先查（不是问题，别拿去问用户）

| 查什么 | 命令 / 位置 | 查到后 |
|---|---|---|
| OS / shell | `uname -srm`；`$PSVersionTable.PSVersion` | 有值 → 填 E1；`unknown` 才问。 |
| harness | `command -v omp codex claude`；`~/.omp/agent`、`~/.codex`、`~/.claude` | 有值 → 填 E2；0 或 ≥2 才问。 |
| home / 目标 | `$HOME` / `$env:USERPROFILE` | 默认用户级；要换路径 → 记 `--target`，不另问。 |
| 仓库源目录 | installer 的 `Find-SourceRoot`；`--source` | 找到 → 不问；退 4 才问“仓库解压到哪”。 |
| 半装 / 旧版 | 搜 `agentrule:entry v1`；找 `.agentrule-deploy/*/manifest.json` | 命中 → STOP-07，问修复/升级/卸载重装/放弃。 |
| 现有配置 | 入口文件行数 + sha256 | 非空 → 填 E4；空 → 直接新建。 |
| 联网 / git | 默认不联网、不 commit/push | 某步确实要下载/提交 → STOP-08/09，单独问。 |
| 验收 | `verify.ps1 --harness <h> --target <home>` / `verify.sh --harness <h> --target <home>` | 默认跑；用户拒绝 → 记录并降级只读检查。 |
| 备份保留 | 默认全部保留 | 用户提磁盘空间 → 问；任何删除前单独确认。 |

## 其余停点（不在本表重复）

`STOP-04` 改既有键（已并入 E4）、`STOP-05` 提权、`STOP-07` 半装、`STOP-09` 写盘验收、`STOP-10` 缺依赖、`STOP-11` 备份不可写、`STOP-13` 远程/WSL、`STOP-14` 全自动 → 按 `PROTOCOL.md` §4 停；命中时用该 STOP 的原文问，不另造问题。

## 什么算“答了”

- 用户明确选了一个选项 → 算。
- 用户说“你看着办 / 随便 / 都行 / 不知道” → 不算：可默认项按默认执行并记 `delegated`；必问项仍停。
- 用户没回 → 不算，不许开工；两轮后转 `BLOCKED`。

## 为什么只有 12 问

能探测的不问：OS、harness、home、源目录、半装、现有配置都先查（见上表）。其余低频/破坏性停点走 `PROTOCOL.md` §4 的 STOP，不在本表重复。装不下不是问题集太小，是问题集太大；这份文件只留每次部署都会改变计划的决策。
