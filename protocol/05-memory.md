# 记忆
> EN: What memory may decide, what only disk may decide, and how to edit a shared file.

## 1. 两层：记忆给启发，盘上给事实

| 层 | 给什么 | 典型内容 |
|---|---|---|
| 记忆（模型自带、会话摘要、规则书） | **启发**：怎么下手、哪条路是死的 | 「这类活先跑一条门」「整份读 transcript 是浪费」 |
| 盘上（仓库当前内容、命令输出、用户这一句） | **事实**：是什么、多少、谁定了什么 | `git log`、`stat`、测试输出、brief |

- 要写进交付物的数字、路径、状态，必须来自盘上或刚跑过的命令；只有记忆来源的标 `[UNVERIFIED]`。
- 冲突时**盘上赢**。记忆与仓库不一致 = 记忆过期：先改行为，再更新记忆。
- 子代理的断言不是事实：升级成你的结论前，自己看一遍源头。
- 会漂的东西（计数、状态、版本）不留在记忆里，写进板或产物。

## 2. 常驻只放铁律和入口

规则书不是百科。整目录预载 = 每轮付一遍 token，换回来的是「读过」的错觉；用到哪篇打开哪篇。

## 3. 改共享文件之前

多个会话可能同时改同一份规则书或配置，读数只有几分钟保鲜期。五步，缺一步就别落笔：

1. **占位**：在派发看板上开一张卡，用 `--scope` 写住这条路径（命令形状见 [`protocol/02-dispatch.md`](02-dispatch.md)；看板工具不在本仓库，自己实现）。
2. **快照**：`stat` mtime + `sha256sum`，记下这两个值。
3. **备份**：同目录 `*.before-<topic>-<date>`，只留最新一份。
4. **最小 edit**：只改这次点名的那一处；改完 `diff` 全文，重算受影响的计数。
5. **中止条款**：落笔前 mtime 或 hash 与快照不符 = 有人插进来了 → 停、重读、重做，不许把旧内容盖回去。

不用文件锁、不设只读属性；这两样都会让下一个会话以为路径安全了。

## 4. 跨会话记忆

- 收工写一块台账（七段），有字符与行数硬上限，超了重写不截断；到阈值由下一个真正接手的人合并。
- 台账是索引不是档案：结论带证据指针，不抄 transcript。
- 格式与判据见 [`library/tooling/knowledge.md`](../library/tooling/knowledge.md)。
