# 本机笔记（示例）

> EN: Which fields a MACHINE.md needs, and what must not go in one.

> **这是某台机器 `MACHINE.md` 脱敏后的形状，不是规范。** 具体值已删掉，只留字段和判据。你的机器应该长得不一样：路径、盘符、服务名、故障都不一样。
> **照它的结构，不要照抄内容。** 每一节都注明「记什么」和「为什么值得占一行」；没有对应内容的节直接删掉，不要为了凑格式编一条。

一台机器为什么需要一页笔记：**每个会话都从零开始。** agent 不知道这台机器的桌面真实路径、不知道哪个故障已经查过、不知道哪条命令在这里会静默失败。这一页就是给它用的缓存——写结论和指针，不写过程。

## 0. 开头三行（必须有）

```markdown
# 本机
- 这是 <谁的> 的 <OS> 机器；笔记日期 <YYYY-MM-DD>。
- 只写这台机器特有的事实；通用规则不进这里（那是 protocol/ 的事）。
- 每条事实带日期或重测命令；没有日期的现值按过期处理。
```

## 1. 机器标识

- **记什么**：OS 与版本、架构、shell 与版本、是不是 WSL、家目录的真实位置。
- **为什么**：命令方言、路径分隔符、编码、大小写敏感性全由它决定。同一条命令在 PowerShell 5.1 和 7 上能跑出两种结果。
- **重测**：`uname -srm` / `$PSVersionTable.PSVersion` / `[Environment]::OSVersion.VersionString`。

## 2. 产物落盘

- **记什么**：桌面真实路径、项目内产物目录、跨项目产物目录、凭据只允许落在哪。
- **为什么**：写错位置 = 产物找不到；凭据落错 = 进仓库、进报告、进会话记录。
- **重测**：桌面取注册表 `User Shell Folders` 的 `Desktop` 值，不要假设是 `~/Desktop`——重定向过的机器上那个路径是废弃的。

## 3. 已知未解的故障

每个故障一张表：现象 / 判定键 / 已排除 / 下一步 / 完整档案在哪。

- **为什么**：不写，下一个人会把同一件事重新审计一遍，花掉一天。
- **判定键**：用哈希或故障桶这类稳定的键，**不要用停止码**——同一个底层异常在不同上下文会变成不同停止码。反过来也别过度归一：同一个码可能对应另一个故障。
- **判据**：写清「已排除」用了哪条命令，否则下次还会被当成嫌疑。

## 4. 排查顺序（这台机器上走过的路）

- **记什么**：先做什么、再做什么、哪条是死路、哪条会挂起。
- **为什么**：工具在这台机器上的行为可能和文档相反——某个符号服务器会无限挂起、某个 dump 目录不提权就静默返回空。这类事实只在这台机器上成立，通用文档里没有。
- **判据**：一条一行，写成「先 X → 再 Y → 别 Z」。

## 5. 被改过的系统配置

每行五格：**项 / 现值 / 改动日期 / 回滚文件 / 重测命令**。

- **为什么**：现值会随驱动和系统更新漂。不带日期的现值，是下一个人的错误引用源。
- **判据**：引用前重跑一次；发现和笔记不一致，先改笔记再引用。
- **回滚**：写清备份文件名与位置；备份丢了就写「备份已灭失」，别写「可回滚」。

## 6. 网络限制

- **记什么**：到不了的站、必须换网络才能做的动作、本地代理在不在、哪些站只能浏览器访问。
- **为什么**：同一条命令在家里能跑、在受限网络里挂住，agent 会误判成「服务坏了」，然后去改配置。

## 7. 别做的

- **记什么**：用户明令禁止的动作（重负载程序、杀某个进程）、已知的误判方向、不能引用的证据类型。
- **为什么**：这是唯一一节「用户原话」比推理更权威的地方。照抄原话，注明日期和说话人角色（不写账号）。
- **派发**：这一节要能被粘进 brief——派活前查一眼，比事后道歉便宜。

## 8. 未决事项

- **记什么**：现状 + 待办 + 卡在什么条件上。
- **为什么**：下一个人要知道哪件事不该重新讨论。
- **判据**：写「等谁答什么」，不写决策者的名字；状态变了就改这一节，别留在正文里。

## 不该写进这一页的

- **凭据**：账号、密码、token、cookie、私钥、TOTP。要记就记「在 `<vault>`」，不记值。
- **一次性的跑测流水**：完整日志、逐条命令输出。那是报告，放归档；这里只放结论和指针。
- **会漂的现值而不带日期**：磁盘余量、进程列表、版本号、注册表值。
- **别人机器的资产**：换一台机器这一页重写，不要把上一台的哈希、盘符、服务名搬过来。
- **磁盘一问就有的事实**：文件在不在、多少行。让 agent 自己跑一条命令，别占常驻上下文。
